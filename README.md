# 人物カード

生年月日から四柱推命・九星気学・動物タイプ・数秘術の属性を算出し、人物ごとの「カード」として蓄積する Web アプリです。

> 占いに基づく参考情報です。採用・評価・契約などの重要な判断の根拠にしないでください。
> 他の人の生年月日を登録する際は、本人の了承を得てください。

## 使い方（PC）

```bash
npm install
```

```bash
npm run dev
```

表示された `http://localhost:5173/` を Chrome で開きます。

| コマンド | 内容 |
|---|---|
| `npm run dev` | 開発用サーバーを起動 |
| `npm test` | 計算ロジックと同期のテスト |
| `npm run build` | 公開用のファイルを `dist/` に作成 |
| `npm run preview` | `dist/` の中身を手元で確認 |

## データの扱い

- データは端末内（IndexedDB）にのみ保存します。サーバーや外部 API は使いません。
- 端末間の同期は「同期ファイル」方式です。同期ファイルを OneDrive などの共有フォルダに置き、各端末でボタンを押して読み書きします。
  - PC（Chrome / Edge）：同期ファイルの場所を一度決めれば、「同期」ボタン1回で読み込み・統合・書き戻しを行います。
  - iPhone：「① 読み込む」→「② 保存する」の2ステップです。
- パスフレーズを設定すると、同期ファイルを暗号化します（AES-GCM）。両方の端末で同じ言葉を設定してください。
- 統合のルール：同じカードは更新日時が新しい方を採用します。削除も同じように伝わります。

## 計算の仕様

- 四柱推命：年・月・日の三柱。年柱は立春、月柱は節入りで切り替え。節入りの日時は `lunar-typescript` で求め、日本時間に直して使用。
- 節入り当日の生まれは「境界日」として、節入り前後の両方の候補を表示（主表示は節入り後）。
- 日柱の区切りは 0 時。時柱と大運は算出しません（出生時刻・性別を使わないため）。
- 通変星は蔵干の本気で引いています。
- 九星気学：本命星は立春基準の年、月命星は節月。
- 動物タイプ：日柱の十二運から 12 動物を決定。本アプリ独自の表示で、市販の動物占いの結果と一致しない場合があります。
- 数秘術：生年月日の各桁の合計。11・22・33 はマスターナンバーとして保持。
- 対応範囲：1901 年〜2099 年。

## チーム分析・年運・Excel 出力

- チーム分析（2人以上）：相性マトリクス、五行の偏り、役割の偏り（月柱の通変星を5グループに分類）、不足要素と補い方、配置の提案。
- 年運タイムライン：流年干支と命式の関係（通変星、十二運、合・冲・刑・害、干合、空亡の年）と、九星の年盤での本命星の回座位置から、年ごとの傾向を表示。複数人の比較表つき。年の始まりは立春。
- 「動きやすい年／安定の年／整える年」の区分は、`src/engine/config.ts` の `YEAR_POINTS` の配点の合計で決めています。
- Excel 出力：設定画面から、カード一覧と全組み合わせの相性結果を .xlsx に出力。

## 計測ログとケーススタディ

- 計測ログ：相性・チームの分析を表示すると、数秒後に「誰について、いつ見たか」を自動で記録。同じ組み合わせは1行にまとめ、点数は表示のたびに計算します。
- ケーススタディ：相性・チーム・カード詳細の「ケースとして記録」から、場面、見立て、実際に起きたこと、学び、役立ち度、タグを記録。記録時点の分析結果（点数など）を控えとして保存します。一覧は「記録」→「ケース」。
- どちらも同期ファイルとバックアップの対象で、ケースは Excel 出力にも含まれます。
